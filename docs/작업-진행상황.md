### 에러 핸들러 / 시나리오 설정 (확정)

| 대상 | 설정 | 근거 |
|---|---|---|
| RSS 2 | `Retry` — 재시도 2, 간격 5분 | E-01 |
| HTTP 9 | **`Resume`** (출력 비움) | E-06. `Retry`를 걸면 저장까지 막혀 원문 링크를 잃는다 |
| Notion 15 | `Retry` — 재시도 2, 간격 5분 | E-09 |
| Store incomplete executions | **Yes** | 꺼져 있으면 `Retry`가 동작하지 않는다 |
| Process data in order | **No** | ⚠️ 켜면 미완료 실행 1건이 이후 모든 예약 실행을 막아 S1이 통째로 날아간다 |
| Keep data confidential | No | 켜면 로그가 안 남아 디버깅·제출 스크린샷 불가 |

> Notion 15는 **Legacy 모듈**이다. 지금 작동하므로 건드리지 않되, 7일 중 저장이 실패하면
> 이걸 먼저 의심한다.

### 6번 모듈 변수 (확정)

칩은 `5.array` 하나뿐이고 `"title"`, `"url"`, `"dateCreated"`, `"id"`, `"description"`은 **전부 평문**이다.

```
제목        get(first(sort(5.array; desc; dateCreated)); "title")
링크        get(first(sort(5.array; desc; dateCreated)); "url")
본문        replace(replace(get(first(sort(5.array; desc; dateCreated)); "description"); "/<[^>]*>/g"; " "); "/[\x22\x5C\n\r\t]/g"; " ")
발행일시     get(first(sort(5.array; desc; dateCreated)); "dateCreated")
중복방지키   ifempty(get(first(sort(5.array; desc; dateCreated)); "id"); md5(get(first(sort(5.array; desc; dateCreated)); "url")))
제목_json    replace(get(first(sort(5.array; desc; dateCreated)); "title"); "/[\x22\x5C\n\r\t]/g"; " ")
```

`제목_json`은 **Gemini에 보낼 때만** 쓴다. Notion 제목 속성에는 원본 `제목`을 넣는다.
`\x22`=`"`, `\x5C`=`\`. 기사 본문의 따옴표가 JSON을 깨뜨리는 것을 막고 HTML 태그도 같이 제거한다.

## 6. 이미 밟은 지뢰 (다시 밟지 말 것)

| 증상 | 진짜 원인 |
|---|---|
| `SyntaxError: unterminated string literal` | 긴 한 줄 명령이 붙여넣다 두 줄로 잘림 → **`python check_feed.py`** 를 쓴다 |
| `references non-existing module [N]` | Make 모듈 번호는 **만든 순서**. 명세서 번호와 다르다 → **칩을 클릭해서 넣을 것** |
| Aggregated fields에 `guid`가 없음 | Make RSS는 guid를 **`id`** 로 내보낸다 (`link`→`url`, `pubDate`→`dateCreated` 와 같은 케이스) |
| Notion `Search` → `No matches found` | DB 이름이 `새 데이터베이스`였음. Make는 **DB 이름**으로 찾는다 |
| 주제와 무관한 기사가 전부 통과 | `Add OR rule`은 **새 그룹을 만든다.** 조건마다 그룹이 생겨 `제목에 광고 없음` 하나만으로 통과했다. 2·3번째 조건은 **`Add AND rule`**로 넣어야 하고, 작업 후 `or` 구분선은 **하나만** 보여야 한다 |
| 특정 키워드만 조용히 매칭 안 됨 | 마크다운 **표**에서 정규식을 복사해 `\|`가 섞임 (`인공지능\|bLLM\b`). 명세서의 **코드블록**에서 복사할 것 |
| Gemini `404 no longer available to new users` | `gemini-2.5-flash`가 신규 계정에 닫힘. AI Studio > 비율 제한에서 **RPD `0/0`이 아닌** 모델을 고른다 |
| Gemini `400` + Google HTML 에러 페이지 | GET 요청에 본문을 실어 보냄. `Body content type`을 **비워야** 한다 (`{}`도 안 됨) |
| `Body structure` 필수라며 막힘 | `Body input method`가 `Data structure`로 바뀐 것. `JSON string`으로 되돌린다 |
| 변수 칸에 식이 두 줄 | 기존 식을 지우지 않고 새 식을 붙임 → 값이 두 번 이어붙는다 |
| ZDNet 피드가 매일 실패 | 주소가 404. `config.py`에서 제거됨 |
