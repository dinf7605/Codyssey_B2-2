## 5. 다음에 할 일 (순서대로)

### 🔴 1순위 — Notion DB 정리 (이게 없으면 뒤가 안 나감)

현재 상태: 페이지 `기술 뉴스 아카이브` 안에 **인라인 DB `새 데이터베이스`** 가 있고, **속성이 하나도 없다.**
연결(Connections)에 `Make` 와 `코디세이프로젝트` 통합은 **이미 추가되어 있다.**

- [ ] DB 이름을 `새 데이터베이스` → **`기술 뉴스 아카이브`** 로 변경
      (Make의 `Search`는 페이지가 아니라 **DB 이름**으로 찾는다. 이게 `No matches found`의 원인이었다)
- [ ] 속성 9개 생성

| 속성명 | 타입 | 주의 |
|---|---|---|
| `제목` | 제목 | 기본 `이름` 칸을 개명 |
| `요약문` | 텍스트 | |
| `원문 링크` | URL | **가운데 띄어쓰기** |
| `발행일시` | 날짜 | **시간 포함 켜기** |
| `출처` | 선택 | 옵션 `전자신문` 미리 생성 |
| `중복방지키` | 텍스트 | 없으면 Notion 필터가 `property does not exist`로 실패 |
| `수집일시` | 날짜 | **시간 포함 켜기** |
| `감성` | 선택 | 보너스 |
| `썸네일` | 파일 | 보너스 |

- [ ] (선택) 인라인 DB → 전체 페이지 전환: DB 왼쪽 `⋮⋮` → `전체 페이지로 전환`

### 🔴 2순위 — Make 수정 3건 (5분)

- [ ] **필터 "매칭 있음"**: `{{length(4.array)}}` → `{{length(5.array)}}`
- [ ] **Set multiple variables(6번)**: 변수 5개의 `4.array` 를 전부 `5.array` 로
- [ ] **변수 이름**: `중복방지` → **`중복방지키`** (뒤에서 `{{6.중복방지키}}`로 참조함)
- [ ] **초록 칩 제거**: `발행일시`와 `중복방지키`에 매핑 칩이 잘못 들어가 있다

수정 후 최종 형태:

```
제목        get(first(sort(5.array; desc; dateCreated)); "title")
링크        get(first(sort(5.array; desc; dateCreated)); "url")
본문        substring(get(first(sort(5.array; desc; dateCreated)); "description"); 0; 4000)
발행일시     get(first(sort(5.array; desc; dateCreated)); "dateCreated")
중복방지키   ifempty(get(first(sort(5.array; desc; dateCreated)); "id"); md5(get(first(sort(5.array; desc; dateCreated)); "url")))
```

> **칩은 `5.array` 하나뿐이다.** `"title"`, `"url"`, `"dateCreated"`, `"id"` 는 전부 평문이어야 한다.
> `get(대상; 이름)`의 두 번째 자리는 **이름을 적는 칸**이라 값(칩)을 넣으면 빈 값이 나온다. 에러는 안 난다.

### 🟡 3순위 — Notion 조회 블록 마무리

## 6. 이미 밟은 지뢰 (다시 밟지 말 것)

| 증상 | 진짜 원인 |
|---|---|
| `SyntaxError: unterminated string literal` | 긴 한 줄 명령이 붙여넣다 두 줄로 잘림 → **`python check_feed.py`** 를 쓴다 |
| `references non-existing module [4]` | Make 모듈 번호는 **만든 순서**. 명세서 번호와 다르다 |
| Aggregated fields에 `guid`가 없음 | Make RSS는 guid를 **`id`** 로 내보낸다 (`link`→`url`, `pubDate`→`dateCreated` 와 같은 케이스) |
| Notion `Search` → `No matches found` | DB 이름이 `새 데이터베이스`였음. Make는 **DB 이름**으로 찾는다 |
| 주제와 무관한 기사가 전부 통과 | Make 필터의 OR는 조건을 더하는 게 아니라 **그룹을 나눈다**. 제외 조건을 모든 그룹에 반복해야 함 |
| ZDNet 피드가 매일 실패 | 주소가 404. `config.py`에서 제거됨 |
